# ATLAS · 성격과 재능의 지도

한국어 심층 자기탐색 웹 앱입니다. 400개 자기보고 문항과 실제 수행 과제, 난제 해결 작업, 행동 증거 기록을 함께 살펴봅니다.

이 프로젝트는 **검증 전 연구용 초안**입니다. 기존 검사보다 정확하다는 근거, 인구 규준, IQ 또는 천재성 판정 기능은 없습니다. 문항 수가 많다는 사실만으로 정확도가 입증되지 않습니다.

## 구성

| 부분 | 분량 |
| --- | ---: |
| 성격·행동 성향 30개 축 | 240문항 |
| 재능·사고 습관 20개 축 | 160문항 |
| 반복·응답 표시 점검 | 12문항 |
| 논리·수리·공간·언어·인과·확률 수행 | 36과제 |
| 난제 해결 작업 | 8과제 |

총 456개 문항·과제와 50개 세부 특성 해석을 제공합니다. 행동 사례 6영역과 7일 관찰 기록도 작성할 수 있습니다.

## 주요 기능

- 현재 브라우저에 자동 저장하고 이어서 응답
- 자기보고와 실제 수행 결과를 구분하여 표시
- 반복 문항의 차이와 응답 점검 결과 확인
- 수행 답변 제출 후 정답·해설 공개
- 확신도와 정답 여부를 함께 사용한 Brier 점수
- 세부 특성별 해석, 대안 설명, 확인할 실험
- 답변 JSON 내보내기·불러오기, Markdown 보고서, 인쇄/PDF 저장
- 새 회차와 이전 자기보고 축 점수 비교
- 브라우저가 지원하는 경우 진행 읽기·영역 열기 WebMCP 도구

## 로컬 실행

Python 3으로 정적 파일 서버를 실행합니다. npm 패키지 설치나 빌드 단계는 필요하지 않습니다.

```bash
git clone https://github.com/tomeido/atlas-self-discovery.git
cd atlas-self-discovery
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. Windows에서 `python3` 명령이 없으면 `python` 또는 `py -3`를 사용하세요. JSON 문항을 읽기 때문에 HTML 파일을 직접 여는 대신 HTTP 서버를 사용해야 합니다.

`dist/` 전체를 함께 정적 호스팅하면 됩니다. Google Fonts를 불러오며, 연결되지 않으면 시스템 글꼴을 사용합니다.

## Vercel 배포

이 저장소를 Vercel 프로젝트에 연결합니다. 저장소 루트의 `vercel.json`이 `dist`를 배포 폴더로 지정하고, 프레임워크·설치·빌드 단계를 생략합니다. 앱은 이미 작성된 HTML/CSS/JavaScript 파일로 구성되어 있습니다.

Vercel의 **Root Directory는 저장소 루트(기본값)**로 유지하세요. `dist`를 Root Directory로 중복 지정할 필요는 없습니다. 연결된 `main` 브랜치의 변경은 Vercel에서 자동으로 재배포합니다.

첫 화면에 404가 나오고 `/dist/index.html`만 열린다면 저장소 루트가 출력 폴더로 배포된 상태입니다. 최신 `vercel.json`이 포함된 커밋을 재배포하고 Output Directory가 `dist`인지 확인하세요.

## 검증

Node.js와 Python 3으로 다음을 실행합니다.

```bash
node validate.mjs
python3 validate_performance.py
node --check dist/app.js
```

검증 스크립트는 문항 수·스키마·중복 ID·역채점·미응답 처리·채점 범위·Brier 점수·답변 파일 복원·잘못된 파일 거부를 확인합니다. 수행 검증은 수치·유한 상태 24개를 계산하고, 36개 정답 키 문자열을 확인합니다. 정답 위치는 A/B/C/D 각각 9개입니다. 언어·인과 문항은 논리 검토를 거쳤습니다.

이 확인은 소프트웨어와 정답 키의 일관성을 점검하는 것이며, 심리측정의 신뢰도·타당도 검증을 대신하지 않습니다. 실제 브라우저별 UI 검증과 대표 표본 연구는 별도로 필요합니다.

## 채점과 해석

각 자기보고 축은 8문항이며 2개가 역채점 문항입니다. 응답 범위는 1–7, 역채점은 `8 − 응답`입니다. `0`은 경험 없음/판단 어려움으로 평균에서 제외합니다. 유효 응답이 6개 이상일 때만 `(평균 − 1) / 6 × 100`을 반올림하여 표시합니다.

이 0–100 값은 원응답의 선형 환산값이며 백분위가 아닙니다. 33/67 설명 구간과 최소 6개 응답 기준은 공개된 설계 규칙이며 경험적으로 검증된 경계값이 아닙니다. 50개 축이 서로 독립된 능력이라는 뜻도 아닙니다.

수행 결과는 이 문항 집합에서의 정확도입니다. Brier는 확률 예측 품질이며 순수한 메타인지 능력 지수가 아닙니다. 개방형 난제 해결 작업은 사용자가 증거 수준을 자기평가합니다. 단일 천재성 총점, 자동 창의성 판정, 임상 진단을 산출하지 않습니다.

## 개인정보와 저장

응답을 서버로 전송하는 코드나 분석 추적기는 없습니다. 답변은 브라우저 `localStorage`에 저장되므로 다른 기기에 자동 동기화되지 않습니다. 브라우저 데이터 삭제나 사생활 보호 모드 종료로 기록이 사라질 수 있습니다. 중요한 기록은 JSON으로 내보내 보관하세요.

답변 JSON은 개인 정보가 포함될 수 있으므로 이 저장소에 커밋하지 마세요. 현재 저장소에는 앱·문항·검증 코드만 포함하며 실제 응답, 인증 정보, 기존 서비스의 내부 배포 설정은 포함하지 않습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `dist/index.html`, `dist/style.css` | 화면 구조와 스타일 |
| `dist/app.js` | 응답·탐색·저장·내보내기·결과 화면 |
| `dist/core.js` | 채점·응답 검토·불러오기 검증 |

| `dist/frontier-challenges.json` | 난제 해결 8과제와 평가 기준 |

문항과 해석은 이 앱을 위해 작성되었습니다. 참고한 기존 검사나 연구의 타당성이 이 앱에 자동으로 적용되지 않습니다. 참고 자료와 추가 검증 계획은 앱의 ‘설계와 해석 근거’ 화면에서 확인할 수 있습니다.
